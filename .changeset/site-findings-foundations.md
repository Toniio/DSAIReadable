docs: Foundations and token descriptions that contradicted the tokens or the components. Color: `color.text.action.default` is `violet.300` in dark mode and `color.border.focus` `mist.400`, where the tables gave `violet.400` and `mist.500`, and action text on the default surface measures 9.81:1 in dark mode, not 4.93:1. Motion: the "Standard hover" example puts `hover:bg-muted` on a `bg-background` surface, where it sat on a Card whose `bg-card` reads the same token and showed no change. Content: the Overriding table adds MessageScrollerViewport, MessageScrollerButton, QuestionnaireProgress and the four Questionnaire buttons, and writes the slot `Remove {item}`. Spacing: the Layout table adds `space.layout.sidebar`, `sidebar-mobile` and `sidebar-icon`, with `w-sidebar`, `w-sidebar-mobile` and `w-sidebar-icon`. Typography: the typeface loader is `lib/fonts.ts`, not `layout.tsx`. Elevation and the `zindex.*` descriptions: menus and popovers draw `z-popover` (1500), not `z-dropdown`; seven components still raise one of their parts with `z-dropdown`, against the local-stacking rule; the Sonner `Toaster` does not read `z-toast`, so a toast is not "always visible above other layers" through it. Calendar: a Calendar in a `CardContent` loses the fill of a range's middle days and of today, since `bg-muted` and the card read the same token; place it in a `Popover`. `space.layout.content-sm` recommends `max-w-2xl`, where it recommended an arbitrary value the ESLint plugin rejects. "dropdown" is spelled one way, without a hyphen, across the specs, the component JSDoc and the token descriptions, and `npm run lint:language` rejects the hyphenated spelling.
