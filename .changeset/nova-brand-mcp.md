mcp: `dsaireadable_get_tokens` and `dsaireadable_get_design_system_overview` report the nova brand: its values as `nova_light` and `nova_dark`, next to `light` and `dark`, and an overview field that lists the brands and the class that turns each on. `dsaireadable_get_typography` adds `text_roles`, each role with its size in each brand. The served rules no longer say that every component is square: a screen next to components uses the radius and text roles, which follow the brand.
