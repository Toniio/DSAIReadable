component-api: Add a second brand, nova, next to lyra, the default. The `nova` class on `<html>`, next to `dark`, gives stone neutrals, rounded corners, larger component text and Lora, DM Sans and Geist Mono; every pair meets WCAG 2.2 AA in the four themes. New tokens: `radius.surface`, `control`, `item`, `inset`, `mark` and `pill` (classes `rounded-surface`…), `typography.size.ui`, `description`, `title` and `control` with their line heights (classes `text-ui`…), `typography.font-family.body` and `heading` (classes `font-body`, `font-heading`), `color.background.card`. New registry item: `theme-nova`, opt-in, with its fonts. Components now name these roles, and lyra resolves each to the value it replaces, so lyra's rendering does not change. Two precedences move, in lyra too: under `asChild`, where no merge runs, a fixed `rounded-*` or `text-*` class on the child that sorts after the role, such as `rounded-lg` or `text-xl`, now wins over the component's role; and the last child of a `ButtonGroup` takes the control radius on its end corners, over a radius set on it. The components import `cn` from the new `@/lib/cn`, which knows the roles; `lib/utils.ts` stays stock, so installing never asks to overwrite it.
