## Role

A linear progress bar that shows how far an operation or a process has gone, built on the Radix UI `Progress` primitive.

## Usage

- Show the progress of a file download or upload
- Show how far along a multi-step process is (a form, onboarding)
- Show a completion rate (a profile 75 % complete)
- Show the progress of a background operation (loading data)
- Show a ratio or a percentage visually (quota used)

## Constraints

- **MUST NOT** — show indeterminate progress without saying so: set `aria-valuetext` or an explicit label
- **MUST NOT** — show more than one `Progress` bar per section
- **MUST** — name the bar (`aria-label` or a tied `<label>`)
- **MUST** — keep `value` between 0 and `max` (100 by default): out-of-range values are not handled
- **MUST NOT** — serve as a data gauge (temperature, stock…): `Progress` expresses how far a task has gone

## Dependencies

- `radix-ui` (`Progress`) — the `Progress.Root` and `Progress.Indicator` primitives
- `cn` (`@/lib/utils`) — the class-merging utility

## Accessibility

**Pattern**: Progress bar (`role="progressbar"`, Radix Progress)

**Role**: `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`; without a `value`, the bar is indeterminate.

**Keyboard**:

No keyboard interaction.

**Accessible name**: Required: `aria-label` or `aria-labelledby` ("File upload"). Without a name, a screen reader announces an anonymous bar.

**Pitfalls**:

- Value changes are not announced continuously: announce the key steps (done, error) through an `aria-live` message.
- Show the value as text as well when it matters ("45 %").
