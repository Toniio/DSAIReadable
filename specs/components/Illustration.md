## Role

A placeholder for illustrations and decorative images, used in split-screen layouts, error pages, empty states and onboarding.

## Usage

- The illustration panel of a split-screen sign-in page
- An empty state
- Onboarding or a walkthrough
- Error pages (404, 500)

## Constraints

- **MUST** — provide a descriptive `alt`: it feeds `role="img"` and `aria-label`
- **MUST** — replace this placeholder with real illustrations before production
- **MUST NOT** — display a content image → use `<img>` or `next/image`
- **MUST** — set the dimensions through `className`: the container imposes none
- **MUST** — in an interface that is not in English, translate the default alternative text (`UI_STRINGS.illustration`) through `alt`

## Dependencies

- `cn` (`@/lib/utils`) to merge classes
- No external dependency — the placeholder SVG lives inside the component

## Accessibility

**Pattern**: Image (`role="img"`)

**Role**: `role="img"` with `aria-label` = `alt`; `alt=""` makes the illustration decorative (`aria-hidden`).

**Keyboard**:

No keyboard interaction.

**Accessible name**: `alt` describes what the illustration adds. The default (`UI_STRINGS.illustration.alt`, "Illustration") adds nothing: replace it, or pass `alt=""`.

**Pitfalls**:

- Most supporting illustrations are decorative: `alt=""`.
