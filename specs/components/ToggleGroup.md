## Role

A group of toggle buttons — exclusive or multi-select — built on Radix ToggleGroup, sharing one variant and size through context.

## Usage

- Switch between views (list, grid, table)
- Pick one filter out of several exclusive options
- Switch a display mode (light / dark, compact / expanded)
- Select several tags or categories (`type="multiple"`)
- Build a formatting toolbar (bold, italic, underline)

## Constraints

- **MUST** — pass `type="single"` for an exclusive selection, `type="multiple"` otherwise
- **MUST** — give the `ToggleGroup` an `aria-label` that describes the group
- **MUST NOT** — serve as navigation → use `Tabs` or `NavigationMenu`
- **Note** — the items are spaced out by default (`spacing={2}`, as in shadcn/ui); `spacing={0}` merges the borders into one segmented control
- **MUST NOT** — redefine `variant` or `size` on a `ToggleGroupItem`, **unless** to set one item apart: the group passes them down

- `radix-ui` — the `ToggleGroup` primitive (Root, Item)

## Accessibility

**Pattern**: [Radio Group](https://www.w3.org/WAI/ARIA/apg/patterns/radio/) (`type="single"`) or a group of toggle buttons (`type="multiple"`) — Radix ToggleGroup

**Role**: in `single` mode, `role="radiogroup"`, each item `role="radio"` with `aria-checked`; in `multiple` mode, `role="toolbar"`, each item a button with `aria-pressed` (Radix ToggleGroup).

**Keyboard**:

| Key                                                     | Action                               |
| ------------------------------------------------------- | ------------------------------------ |
| `Tab`                                                   | Enters the group (a single tab stop) |
| `ArrowRight` / `ArrowLeft` (or `ArrowDown` / `ArrowUp`) | Next / previous item                 |
| `Home` / `End`                                          | First / last item                    |
| `Enter` / `Space`                                       | Turns the item on or off             |

**Accessible name**: Name the group (`aria-label`: "Text alignment"); every icon-only item needs an `aria-label`.

**Pitfalls**:

- For an exclusive choice presented as buttons, `type="single"` gives the expected radio semantics.

## Code example

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
import { ListIcon, GridFourIcon, TableIcon } from "@phosphor-icons/react"

export default function Example() {
  return (
    <ToggleGroup
      type="single"
      defaultValue="list"
      variant="outline"
      size="default"
      aria-label="View"
    >
      <ToggleGroupItem value="list" aria-label="List view">
        <ListIcon />
      </ToggleGroupItem>
      <ToggleGroupItem value="grid" aria-label="Grid view">
        <GridFourIcon />
      </ToggleGroupItem>
      <ToggleGroupItem value="table" aria-label="Table view">
        <TableIcon />
      </ToggleGroupItem>
    </ToggleGroup>
  )
}
```
