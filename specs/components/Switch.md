## Role

A toggle switch that turns a two-state setting on or off, with immediate visual feedback.

## Usage

- Turn a setting on or off (notifications, dark mode)
- An on / off choice in a settings form
- A control whose effect is immediate (no submit needed)
- A visual alternative to a single checkbox

<!-- rule-20: generated from design-system.index.json by scripts/build-spec-choices.ts — do not edit by hand. -->

- **Choice** (`rule-20`) — Pick the selection control from the number of options and the screen width. One value out of 2 to 5 options: `RadioGroup`, with every option visible. Out of 6 to 15: `Select` from `md` up; below `md`, `NativeSelect`, **unless** the options need rich rendering (icons, descriptions) → `Select`. More than 15 options, or search required: `Combobox`. Several values: `Checkbox` up to 5 options, `Combobox` in multiple mode beyond that. An on/off toggle that takes effect immediately: `Switch`.

## Constraints

- **MUST NOT** — serve multiple choices → use `Checkbox`
- **MUST NOT** — serve a choice between two named options → use `RadioGroup`
- **MUST** — pair it with a visible label: `Label` (`htmlFor`), or `Field` with a `FieldLabel`; inside a `Field` as soon as it has a description or an error message (`rule-09`)
- **MUST NOT** — add padding to enlarge the hit area: it is already enlarged (`after:-inset-x-3 after:-inset-y-2`)
- **MUST NOT** — receive a function (callback, event handler) from a server component: it is a client component (`"use client"`), and only serializable props reach it from a server component

## Accessibility

**Pattern**: [Switch](https://www.w3.org/WAI/ARIA/apg/patterns/switch/) (Radix Switch)

**Role**: `role="switch"` on a `button`, with `aria-checked`.

**Keyboard**:

| Key               | Action                          |
| ----------------- | ------------------------------- |
| `Space` / `Enter` | Toggles the state               |
| `Tab`             | Moves focus to the next element |

**Accessible name**: Required: a tied `Label` or an `aria-label`. The label names the setting, not its state ("Notifications", not "On").

**Pitfalls**:

- A switch acts immediately; when the setting only applies once a form is submitted, use a `Checkbox`.

## Code example

```tsx
import { Switch } from "@/components/ui/switch"
import { Label } from "@/components/ui/label"

export default function Example() {
  return (
    <div className="flex items-center gap-2">
      <Switch id="notifications" defaultChecked />
      <Label htmlFor="notifications">Notifications</Label>
    </div>
  )
}
```

## Cross-references

- `Label` — tied to the switch for accessibility
- `Field` — wraps the switch with a label and error messages
- `Checkbox` — the alternative for multiple choices or submitted forms
- `RadioGroup` — the alternative for a choice between named options
- `Toggle` — the alternative for a button with a pressed / unpressed state
