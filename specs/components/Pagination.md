## Role

Sequential navigation through paged result sets, with numbered links, previous / next links and an ellipsis.

## Usage

- Move between the pages of a list of results (tables, grids)
- Show the current page among a set of numbered pages
- Offer "Previous" and "Next" shortcuts for sequential navigation
- Collapse the middle page numbers behind an ellipsis for large sets

## Constraints

- **MUST NOT** — serve as hierarchical navigation → use `Breadcrumb`
- **MUST** — manage the pagination state and URLs yourself: the component holds none
- **MUST NOT** — duplicate `aria-current="page"`, which the active page already carries
- **MUST** — give `PaginationPrevious` and `PaginationNext` a valid `href` or a handler
- **Note** — the ellipsis is hidden from screen readers (`aria-hidden`)
- **MUST** — in an interface that is not in English, translate `UI_STRINGS.pagination` through `text`, `label` and `srLabel`

## Dependencies

- `Button` from `@/components/ui/button` (wraps the pagination links)
- `CaretLeftIcon`, `CaretRightIcon`, `DotsThreeIcon` from `@phosphor-icons/react`

## Accessibility

**Pattern**: Navigation (`nav`) with a list of links

**Role**: A `nav` labeled `UI_STRINGS.pagination.landmark`; a `ul` of links; the current page carries `aria-current="page"`.

**Keyboard**:

No interaction of its own: native links (`Tab`, `Enter`).

**Accessible name**: Previous / next are named by `UI_STRINGS.pagination.previousLabel` / `nextLabel`; the ellipsis by `UI_STRINGS.pagination.ellipsis`.

**Pitfalls**:

- Each page link must be explicit for a screen reader ("Page 3"), not just "3", when the context is not enough.
- After a page change, move focus to the start of the results.

## Code example

```tsx
import {
  Pagination,
  PaginationContent,
  PaginationItem,
  PaginationLink,
  PaginationPrevious,
  PaginationNext,
  PaginationEllipsis,
} from "@/components/ui/pagination"

export default function Example() {
  return (
    <Pagination>
      <PaginationContent>
        <PaginationItem>
          <PaginationPrevious href="/page/1" />
        </PaginationItem>
        <PaginationItem>
          <PaginationLink href="/page/1">1</PaginationLink>
        </PaginationItem>
        <PaginationItem>
          <PaginationLink href="/page/2" isActive>
            2
          </PaginationLink>
        </PaginationItem>
        <PaginationItem>
          <PaginationLink href="/page/3">3</PaginationLink>
        </PaginationItem>
        <PaginationItem>
          <PaginationEllipsis />
        </PaginationItem>
        <PaginationItem>
          <PaginationNext href="/page/3" />
        </PaginationItem>
      </PaginationContent>
    </Pagination>
  )
}
```
