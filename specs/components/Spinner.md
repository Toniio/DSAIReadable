## Role

An animated loading indicator that signals an asynchronous operation is in progress.

## Usage

- Show a `Button`'s `loading` state while a form submits
- Show that a network response is pending (authentication, data loading)
- Stand in for content that is loading (a light alternative to a skeleton)
- Always paired with an `aria-label` that describes the operation

## Constraints

- **MUST** — replace the default `aria-label` (`"Loading"`) with a label that describes the action ("Signing in")
- **MUST NOT** — show more than one `Spinner` in the same area: one indicator
- **Note** — the size is set through `className` (`size-3`, `size-6`): there is no `size` prop
- **MUST NOT** — signal a load that lasts more than 10 s → use `Progress` with a percentage
- **MUST NOT** — add a second `role="status"` in the parent: the component carries it
- **MUST** — the default accessible name comes from `UI_STRINGS.spinner`, in English — override it through `aria-label`

## Dependencies

- `SpinnerIcon` from `@phosphor-icons/react` — the animated SVG icon
- Tailwind CSS's `animate-spin` — the rotation animation

## Accessibility

**Pattern**: Status (`role="status"`)

**Role**: `role="status"` with `aria-label` = `UI_STRINGS.spinner.label`: announced politely.

**Keyboard**:

No interaction.

**Accessible name**: The default label ("Loading") is generic: replace it through `aria-label`, which takes precedence, and make it specific when that helps ("Loading transactions").

**Pitfalls**:

- A spinner inside a button does not replace the button's name: keep the button text, or set `aria-busy` on the button.

## Code example

```tsx
import * as React from "react"
import { Button } from "@/components/ui/button"
import { Spinner } from "@/components/ui/spinner"

export default function Example() {
  const [isLoading, setIsLoading] = React.useState(false)

  return (
    <Button
      type="submit"
      disabled={isLoading}
      aria-busy={isLoading}
      onClick={() => setIsLoading(true)}
    >
      {isLoading ? (
        <>
          <Spinner aria-label="Signing in" />
          Signing in…
        </>
      ) : (
        "Sign in"
      )}
    </Button>
  )
}
```
