## Role

A composable empty state, shown when a view, a list or a section has no data.

## Usage

- Say that a list or a table has no results
- Offer a create action when a collection is empty
- Welcome the user on a dashboard that has no data yet
- Stand in for content that is waiting for its first data
- Report "zero results" after filtering

## Constraints

- **MUST NOT** — report a server error → use an `Alert` with `variant="destructive"`
- **MUST NOT** — show more than one `Empty` per view
- **MUST NOT** — put essential information in `EmptyMedia`: the media is decorative
- **MUST NOT** — exceed two sentences of description; frame it around the action to take
- **MUST** — `EmptyTitle` renders an `<h2>`: pass `as` (`"h3"`…) to follow the page's hierarchy — one level below the heading of the section that holds the empty state. Do not style through `as`: the look is fixed

## Dependencies

- `class-variance-authority` for the `EmptyMedia` variants
- The `cn` utility from `@/lib/utils`

## Accessibility

**Pattern**: None — a composed empty state

**Role**: Plain `div`s, except `EmptyTitle`: a native heading (`<h2>` by default, level set through `as`) that screen readers list.

**Keyboard**:

No interaction of its own; the actions placed in `EmptyContent` are focusable.

**Accessible name**: Not applicable; the `EmptyTitle` text is the empty state's heading.

**Pitfalls**:

- Set `as` from the real hierarchy: the default `<h2>` assumes the empty state fills a view headed by an `h1`. Inside an `h2` section, pass `as="h3"`.
- Do not wrap `EmptyTitle` in a `Heading`: that would nest two headings.
- When the empty state appears after an action (a search with no results), announce it through an `aria-live` region.
- The `EmptyMedia` illustration is decorative unless it carries information: `alt=""` by default.

## Code example

```tsx
import {
  Empty,
  EmptyHeader,
  EmptyMedia,
  EmptyTitle,
  EmptyDescription,
  EmptyContent,
} from "@/components/ui/empty"
import { Button } from "@/components/ui/button"
import { PlusIcon, FolderIcon } from "@phosphor-icons/react"

export default function Example() {
  return (
    <Empty>
      <EmptyHeader>
        <EmptyMedia variant="icon">
          <FolderIcon />
        </EmptyMedia>
        <EmptyTitle>No projects yet</EmptyTitle>
        <EmptyDescription>
          You haven't created a project yet. Start one now.
        </EmptyDescription>
      </EmptyHeader>
      <EmptyContent>
        <Button size="sm">
          <PlusIcon /> Create a project
        </Button>
      </EmptyContent>
    </Empty>
  )
}
```
