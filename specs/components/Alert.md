## Role

A non-modal banner that delivers a contextual message — informational or an error — with a title, a description and an optional action.

## Usage

- Report an authentication error after a failed sign-in
- Tell the user about a system state (session expired, network error)
- Warn before an irreversible action
- Put an SVG icon first to strengthen the visual signal

## Constraints

- **MUST NOT** — show a transient message (toast) → use `Sonner`
- **MUST NOT** — act as a blocking dialog → use `AlertDialog`
- **MUST NOT** — place more than one `Alert` per page section
- **MUST NOT** — add a second `role="alert"` among the children: the root already carries it
- **MUST NOT** — put variable-width content in `AlertAction`, which is absolutely positioned at the top right

## Dependencies

- No internal component is required
- `Button` — the usual content of `AlertAction`
- An SVG icon (Phosphor Icons) — a direct child of `Alert`, which switches the layout to two columns

## Anatomy

| Slot                            | Role                                                               |
| ------------------------------- | ------------------------------------------------------------------ |
| `data-slot="alert"`             | Root `<div>` with `role="alert"`; carries the variant              |
| `data-slot="alert-title"`       | Bold title `<div>`; moves to `col-start-2` when an icon is present |
| `data-slot="alert-description"` | Description `<div>` in a subdued color (`text-muted-foreground`)   |
| `data-slot="alert-action"`      | Action `<div>`, absolutely positioned at the top right             |
| _(implicit icon)_               | First `<svg>` child: spans 2 grid rows, sized `size-4`             |

## Accessibility

**Pattern**: `alert` role (assertive live region)

**Role**: `role="alert"` on the root: screen readers announce the content as soon as it is inserted.

**Keyboard**:

No keyboard interaction of its own; only the interactive elements placed inside receive focus.

**Accessible name**: The title (`AlertTitle`) and the description (`AlertDescription`) make up the announced message.

**Pitfalls**:

- `role="alert"` interrupts whatever is being read: keep `Alert` for important messages that appear in response to the user, not for a static notice present on page load.
- The `destructive` variant does not carry the meaning on its own: the text must say it is an error (icon plus words, never color alone).

## Code example

```tsx
import { Alert, AlertTitle, AlertDescription } from "@/components/ui/alert"
import { WarningCircleIcon } from "@phosphor-icons/react"

export default function Example() {
  return (
    <Alert variant="destructive">
      <WarningCircleIcon />
      <AlertTitle>Incorrect credentials</AlertTitle>
      <AlertDescription>
        Check your email address and password, then try again.
      </AlertDescription>
    </Alert>
  )
}
```
