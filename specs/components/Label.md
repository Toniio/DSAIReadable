## Role

An accessible label tied to a form control, built on Radix `Label.Root`.

## Usage

- Name each form control (`Input`, `Checkbox`, `Select`…) through `htmlFor`
- Pair an icon and text visually, thanks to the built-in `gap-2`
- Mirror the disabled state of the associated control (through `peer-disabled`)

## Constraints

- **MUST NOT** — replace a `Label` with a `placeholder`
- **MUST** — tie every `Label` to its control (`htmlFor` or `aria-labelledby`); no field goes without a visible label
- **MUST NOT** — serve as a section title → use `FieldLegend` or `Heading`
- **MUST NOT** — tie more than one `Label` to a control

## Dependencies

- `Label.Root` from `radix-ui` — provides the native semantic link
- `Field` — coordinates the `disabled` state through the `group/field` class
- `Input` / `Checkbox` — the controls it targets most often

## Accessibility

**Pattern**: Native `label` element (Radix Label)

**Role**: A native `label` tied to a control through `htmlFor`; clicking the label activates the control.

**Keyboard**:

No keyboard interaction of its own.

**Accessible name**: The label text names the associated control.

**Pitfalls**:

- `htmlFor` must match the control's `id`; a label that is not tied to anything names nothing.
- The label stays visible: never replace it with a `placeholder`.

## Code example

```tsx
import { Label } from "@/components/ui/label"
import { Input } from "@/components/ui/input"

export default function Example() {
  return (
    <div className="flex flex-col gap-1.5">
      <Label htmlFor="password">Password</Label>
      <Input id="password" type="password" />
    </div>
  )
}
```
