## Role

A visual stand-in for a person or an entity — a photo, initials or an icon — with support for groups and status badges.

## Usage

- Show a user's profile photo in a header or a list
- Fall back to initials when the image is unavailable
- Stack several avatars with `AvatarGroup` to list participants
- Signal a status (online, notifications) with `AvatarBadge`
- Size it to the context (`sm` in lists, `lg` on profiles)

## Constraints

- **MUST** — provide an `AvatarFallback`, shown when the image is missing
- **MUST NOT** — use `AvatarBadge` without an `aria-label` that says what it signals
- **MUST** — give `AvatarImage` a descriptive `alt`
- **MUST NOT** — show more than 4 avatars in an `AvatarGroup`: beyond that, show the first 3 and put the rest in `AvatarGroupCount`

## Dependencies

- `radix-ui` — the `Avatar` primitive (Root, Image, Fallback)
- The `cn` utility from `@/lib/utils`

## Accessibility

**Pattern**: Image (`img`) with a text fallback (Radix Avatar)

**Role**: `AvatarImage` renders an `img`; `AvatarFallback` only shows when the image fails or is missing.

**Keyboard**:

No keyboard interaction of its own.

**Accessible name**: `alt` is required on `AvatarImage` (the person's name), or `alt=""` when the name is already written next to it.

**Pitfalls**:

- When the name is shown next to the avatar, the fallback initials repeat it: hide them with `aria-hidden`.
- A clickable avatar must be wrapped in a named link or button, not made clickable itself.

## Code example

```tsx
import {
  Avatar,
  AvatarImage,
  AvatarFallback,
  AvatarBadge,
  AvatarGroup,
  AvatarGroupCount,
} from "@/components/ui/avatar"

export default function Example() {
  return (
    <AvatarGroup>
      <Avatar size="default">
        <AvatarImage src="/user1.jpg" alt="Sarah Miller" />
        <AvatarFallback>SM</AvatarFallback>
        <AvatarBadge />
      </Avatar>
      <Avatar size="default">
        <AvatarImage src="/user2.jpg" alt="James Carter" />
        <AvatarFallback>JC</AvatarFallback>
      </Avatar>
      <AvatarGroupCount>+3</AvatarGroupCount>
    </AvatarGroup>
  )
}
```
