## Role

A container that visually joins adjacent buttons, inputs or selects by merging their borders and corners.

## Usage

- Group related actions (for example "Previous / Next")
- Join an input and an action button (a search field with a "Go" button)
- Combine a select and a button in a compact toolbar
- Stack buttons in a column with the `vertical` orientation
- Split sub-groups visually with `ButtonGroupSeparator`

## Constraints

- **MUST NOT** — group unrelated actions → just space them out (`flex gap-*`)
- **MUST NOT** — group more than 5 buttons
- **MUST** — keep `orientation="vertical"` for side toolbars
- **MUST** — only hold children whose borders can merge: the inner corners are removed
- **Note** — a nested group (`has-[>[data-slot=button-group]]`) automatically gets `gap-2`

## Dependencies

- `class-variance-authority` for the orientation variants
- `Slot.Root` from `radix-ui` (used by `ButtonGroupText` when `asChild={true}`)
- `Separator` from `@/components/ui/separator`
- The `cn` utility from `@/lib/utils`

## Accessibility

**Pattern**: Group (`role="group"`)

**Role**: `role="group"` on the root; each button keeps its own semantics.

**Keyboard**:

| Key                 | Action                                                      |
| ------------------- | ----------------------------------------------------------- |
| `Tab` / `Shift+Tab` | Moves from one button to the next (no arrow-key navigation) |

**Accessible name**: Give the group an `aria-label` when its purpose is not obvious ("Text formatting").

**Pitfalls**:

- For an exclusive choice between options, use `ToggleGroup`, which carries the selected state; `ButtonGroup` only groups things visually.

## Code example

```tsx
import { ButtonGroup, ButtonGroupSeparator } from "@/components/ui/button-group"
import { Button } from "@/components/ui/button"

export default function Example() {
  return (
    <ButtonGroup orientation="horizontal">
      <Button variant="outline">Previous</Button>
      <ButtonGroupSeparator />
      <Button variant="outline">Next</Button>
    </ButtonGroup>
  )
}
```
