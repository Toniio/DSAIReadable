## Role

A single-line text (or file) input: the basic building block of every form.

## Usage

- Free text entry (email, password, search)
- File upload (`type="file"`)
- Always paired with a `<Label>` through `htmlFor` / `id`, for accessibility
- Takes an error state through `aria-invalid="true"`, paired with a `<FieldError>`

## Constraints

- **MUST NOT** — take multi-line input → use `Textarea`
- **MUST NOT** — offer a choice among fixed values → use `Select` or `Checkbox`
- **MUST NOT** — replace a visible `Label` with a `placeholder`
- **MUST NOT** — set `autoFocus` on more than one field per view
- **Note** — when disabled, the field shows the `not-allowed` cursor and its value is not submitted

## Dependencies

- `Label` — must be tied through `htmlFor` / `id`
- `Field` — wraps `Input`, `FieldLabel` and `FieldError` to handle the invalid state
- `FieldError` — shows the error message below the input; `FieldDescription` shows the help text

## Accessibility

**Pattern**: Native `input` field

**Role**: Native `input`; its type (`email`, `tel`…) sets the virtual keyboard and the semantics.

**Keyboard**:

The field's native behavior.

**Accessible name**: Required: a tied `Label` (`htmlFor` / `id`) or an `aria-label`. A `placeholder` is not a name.

**Pitfalls**:

- Set `autocomplete` for personal data (WCAG 1.3.5).
- `aria-invalid` styles the error; link the message through `aria-describedby`.

## Code example

```tsx
import { Input } from "@/components/ui/input"
import { Label } from "@/components/ui/label"

export default function Example() {
  return (
    <div className="flex flex-col gap-1.5">
      <Label htmlFor="email">Email address</Label>
      <Input id="email" type="email" placeholder="you@example.com" />
    </div>
  )
}
```
