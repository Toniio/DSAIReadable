## Role

A horizontal or vertical rule that divides sections of content, built on Radix `Separator`.

## Usage

- Split two sections of a `Card` or a form visually
- Divide list or navigation items into logical groups
- Build an "or" divider between two sign-in options ("Or continue with")
- Use the `vertical` orientation to separate inline items (a toolbar)

## Constraints

- **MUST** — keep `decorative` (the default) for a purely visual separator: it is hidden from screen readers
- **MUST** — only pass `decorative={false}` when the separation carries meaning (two distinct sections of an article)
- **MUST** — separate with spacing (`gap`) when a separator adds no meaning
- **MUST NOT** — override the thickness (`h-px` / `w-px`)

## Dependencies

- The `Separator` primitive from `radix-ui` — handles `aria-orientation` and `aria-hidden`

## Accessibility

**Pattern**: Separator (Radix Separator)

**Role**: Decorative by default (`role="none"`); `decorative={false}` gives it `role="separator"` and `aria-orientation`.

**Keyboard**:

No keyboard interaction.

**Accessible name**: Not applicable.

**Pitfalls**:

- Keep the decorative default unless the separator really delimits two groups of content.

## Code example

```tsx
import { Separator } from "@/components/ui/separator"

export default function Example() {
  return (
    <div className="flex flex-col gap-4">
      <p>Sign in with email</p>
```
