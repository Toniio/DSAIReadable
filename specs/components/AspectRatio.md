## Role

A container that locks its content — an image, a video, an embedded map — to a fixed width-to-height ratio.

## Usage

- Show an image or a video at a constant ratio (16/9, 4/3, 1/1…)
- Keep a grid of thumbnails visually consistent
- Frame embedded content (an iframe, a map) without shifting the layout
- Reserve a media element's space before it loads, so it does not push the layout around (_cumulative layout shift_)

## Constraints

- **MUST NOT** — hold free-flowing text: it would be clipped or overflow
- **MUST** — fill the frame with an `absolute` child (`size-full`) or an `object-cover` media element
- **MUST** — pass a single direct child; wrap several elements in a container

## Accessibility

**Pattern**: None — a layout container

**Role**: No role: a `div` that sets its child's ratio.

**Keyboard**:

No keyboard interaction.

**Accessible name**: Carried by the content: a child image has its `alt` (empty when decorative), a video its captions.

**Pitfalls**:

- Cropping must not hide information the image exists to convey.

## Code example

```tsx
import { AspectRatio } from "@/components/ui/aspect-ratio"

export default function Example() {
  return (
    <AspectRatio ratio={16 / 9}>
      <img
        src="/placeholder.jpg"
        alt="Mountain landscape"
        className="size-full rounded-none object-cover"
      />
    </AspectRatio>
  )
}
```
