## Role

A slider that picks a numeric value (or a range) within set bounds, horizontally or vertically.

## Usage

- Set a numeric value within a range (volume, brightness)
- Pick a min / max range (a range slider with 2 thumbs)
- Filter by a range of prices, dates or distances
- Settings forms that give immediate visual feedback

## Constraints

- **MUST NOT** — be used to enter an exact value → a `number` `Input`
- **MUST** — always name the Slider: `aria-label`, or `aria-labelledby` pointing to the `id` of a `<Label>` (`htmlFor` does not name a thumb, which is not a form field). With several thumbs, name each one as well through `thumbLabels` ("Minimum price", "Maximum price")
- **MUST** — give a vertical `Slider` a minimum height (`min-h-40`)
- **MUST** — pick `min`, `max` and `step` so that `max - min` is a multiple of `step`
- **MUST NOT** — receive a function (callback, event handler) from a server component: it is a client component (`"use client"`), and only serializable props reach it from a server component

## Dependencies

- `radix-ui` — the `Slider` primitive (Root, Track, Range, Thumb)

## Anatomy

| Slot                       | Role                                                                                |
| -------------------------- | ----------------------------------------------------------------------------------- |
| `data-slot="slider"`       | Root, a flex container; `role="group"` when there are several thumbs                |
| `data-slot="slider-track"` | The slider's background track                                                       |
| `data-slot="slider-range"` | Colored area that shows the selected range                                          |
| `data-slot="slider-thumb"` | Draggable thumb(s) that set the value; `role="slider"`, carries the accessible name |

## Accessibility

**Pattern**: [Slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/) (Radix Slider)

**Role**: Each thumb carries `role="slider"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`.

**Keyboard**:

| Key                       | Action                                |
| ------------------------- | ------------------------------------- |
| `ArrowRight` / `ArrowUp`  | Increases by one step                 |
| `ArrowLeft` / `ArrowDown` | Decreases by one step                 |
| `PageUp` / `PageDown`     | Increases / decreases by a large step |
| `Home` / `End`            | Minimum / maximum value               |

**Accessible name**: Carried by the thumbs, the only focusable elements. With one thumb, the `Slider`'s `aria-label` or `aria-labelledby` is passed to it. With several thumbs, that name goes to the group (`role="group"` on the root), and each thumb takes its entry from `thumbLabels` — failing that, Radix's generic name, in English ("Minimum" / "Maximum"; "Value 1 of 3"… beyond two).

**Pitfalls**:

- A one-thumb `Slider` with no `aria-label`, `aria-labelledby` or `thumbLabels` has no name (axe violation `aria-input-field-name`).
- With several thumbs, provide `thumbLabels`: Radix's default names do not say what the thumb sets, and they are not translated.
- Show the value as text: the position alone does not convey it.

## Code example

```tsx
import { Slider } from "@/components/ui/slider"

export default function Example() {
  return (
    <Slider
      defaultValue={[25, 75]}
      min={0}
      max={100}
      step={1}
      aria-label="Price range"
      thumbLabels={["Minimum price", "Maximum price"]}
    />
  )
}
```
