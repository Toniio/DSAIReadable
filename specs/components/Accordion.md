## Role

A vertical stack of collapsible panels that shows and hides sections of content.

## Usage

- Break long content into sections the reader expands on demand (FAQ, documentation)
- Reveal details progressively without crowding the initial view
- Group settings or options by category
- Present questions and answers in a compact format
- Walk through a hierarchy of content

## Constraints

- **MUST NOT** — hold critical content that has to stay visible at all times
- **MUST NOT** — nest an `Accordion` inside another: one level only
- **MUST** — give each trigger explicit text, never an icon alone
- **Note** — a disabled trigger drops pointer events and applies `opacity-disabled`
- **MUST NOT** — serve as primary navigation → use `NavigationMenu` or `Tabs`

## Dependencies

- `Accordion` (Root, Item, Header, Trigger, Content) from `radix-ui`
- `CaretDownIcon`, `CaretUpIcon` from `@phosphor-icons/react`

| State    | Description                                                                                                                   |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| default  | Panel closed, caret pointing down                                                                                             |
| hover    | Trigger text underlined                                                                                                       |
| focus    | `FOCUS_RING` (`lib/focus.ts`): `border-ring` border and a `ring-ring/50` ring `--space-focus-ring-width` wide, on the trigger |
| active   | Panel open, caret pointing up, content sliding down                                                                           |

## Accessibility

**Pattern**: [Accordion](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/) (Radix Accordion)

**Role**: Each trigger is a `button` inside a heading, with `aria-expanded` and `aria-controls`; each panel is a `region` labeled by its trigger.

**Keyboard**:

| Key                     | Action                                             |
| ----------------------- | -------------------------------------------------- |
| `Enter` / `Space`       | Opens or closes the focused trigger's panel        |
| `ArrowDown` / `ArrowUp` | Next / previous trigger                            |
| `Home` / `End`          | First / last trigger                               |
| `Tab`                   | Leaves the triggers for the next focusable content |

**Accessible name**: The `AccordionTrigger` text names the button and labels the panel: it must describe the content, not say "See more".

**Pitfalls**:

- Do not put an interactive element inside `AccordionTrigger`: a button cannot contain another one.
- The heading level that wraps the trigger must fit the page's heading hierarchy.

## Code example

```tsx
import {
  Accordion,
  AccordionItem,
  AccordionTrigger,
  AccordionContent,
} from "@/components/ui/accordion"

export default function Example() {
  return (
    <Accordion type="single" collapsible>
      <AccordionItem value="item-1">
        <AccordionTrigger>Section 1</AccordionTrigger>
        <AccordionContent>Content of the first section.</AccordionContent>
      </AccordionItem>
      <AccordionItem value="item-2">
        <AccordionTrigger>Section 2</AccordionTrigger>
        <AccordionContent>Content of the second section.</AccordionContent>
      </AccordionItem>
    </Accordion>
  )
}
```
