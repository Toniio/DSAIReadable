## Role

A multi-line text field that grows with its content (`field-sizing-content`), for free-form text.

## Usage

- Long text (comments, descriptions, messages)
- Form fields that need several lines
- Free-form notes or remarks
- Inside an `InputGroup`, through `InputGroupTextarea`

## Constraints

- **MUST NOT** — take single-line input → use `Input`
- **Note** — the field grows with its content (`field-sizing-content`); set a fixed height through `className`
- **Note** — minimum height: `min-h-16` (4rem)
- **MUST NOT** — redefine the background without its dark counterpart (`dark:bg-input/30` by default)
- **Note** — a server component: it renders without `"use client"`

## Dependencies

- No external dependency (a self-contained component, native HTML)

## Accessibility

**Pattern**: Native `textarea` field

**Role**: Native `textarea`.

**Keyboard**:

Native behavior; `Tab` leaves the field (it does not insert a tab character).

**Accessible name**: Required: a tied `Label` or an `aria-label`.

**Pitfalls**:

- Announce a character limit before it is reached, with a counter linked through `aria-describedby`.
