## Role

Resizable panels: an area split into sections the user adjusts by dragging the handles between them.

## Usage

- Build a resizable multi-panel layout (a code editor, a file explorer)
- Split a screen into adjustable columns or rows
- Let the user decide how the space is shared
- IDE-style interfaces with resizable side panels
- Combine nested horizontal and vertical panels

## Constraints

- **MUST NOT** — serve a fixed-width layout → a CSS grid (`grid`)
- **MUST** — give each `ResizablePanel` a `minSize`, so its content is never crushed
- **MUST NOT** — take away the `ResizableHandle`'s focus or its arrow-key control
- **MUST NOT** — nest `ResizablePanelGroup`s more than 2 levels deep
- **MUST NOT** — mix `vertical` and `horizontal` orientations at the same level

## Dependencies

- `react-resizable-panels` (`Group`, `Panel`, `Separator`)
- `cn` from `@/lib/utils`

## Accessibility

**Pattern**: [Window Splitter](https://www.w3.org/WAI/ARIA/apg/patterns/windowsplitter/) (react-resizable-panels)

**Role**: Each handle carries `role="separator"`, is focusable and exposes its current value.

**Keyboard**:

| Key                                                     | Action                              |
| ------------------------------------------------------- | ----------------------------------- |
| `ArrowLeft` / `ArrowRight` (or `ArrowUp` / `ArrowDown`) | Resizes along the orientation       |
| `Home` / `End`                                          | Minimum / maximum size of the panel |

**Accessible name**: Give the handles an `aria-label` when there are several ("Sidebar width").

**Pitfalls**:

- Resizing must not be required to read the content: every panel must stay usable at its default size.

## Code example

```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"

export default function Example() {
  return (
    <ResizablePanelGroup orientation="horizontal" className="min-h-52">
      <ResizablePanel defaultSize="50%" minSize="20%">
        <div className="p-4">Left panel</div>
      </ResizablePanel>
      <ResizableHandle withHandle />
      <ResizablePanel defaultSize="50%" minSize="20%">
        <div className="p-4">Right panel</div>
      </ResizablePanel>
    </ResizablePanelGroup>
  )
}
```
