## Role

The browser's native drop-down: a light, accessible way to pick one option from a list.

## Usage

- Pick one value out of 6 to 15 options below `md`
- Mobile forms, where the system picker is the most comfortable to use

<!-- rule-20: generated from design-system.index.json by scripts/build-spec-choices.ts — do not edit by hand. -->

- **Choice** (`rule-20`) — Pick the selection control from the number of options and the screen width. One value out of 2 to 5 options: `RadioGroup`, with every option visible. Out of 6 to 15: `Select` from `md` up; below `md`, `NativeSelect`, **unless** the options need rich rendering (icons, descriptions) → `Select`. More than 15 options, or search required: `Combobox`. Several values: `Checkbox` up to 5 options, `Combobox` in multiple mode beyond that. An on/off toggle that takes effect immediately: `Switch`.

## Constraints

- **MUST NOT** — be used when the list has to be filtered by typing → use `Combobox`
- **Note** — the open menu is drawn by the browser and cannot be styled
- **Note** — the options take the system colors (`Canvas`, `CanvasText`)
- **Note** — `size` is a prop of the component, not the native `<select>` attribute: `"sm"` or `"default"`
- **MUST** — provide an empty `<option value="">` as a placeholder

## Dependencies

- `@phosphor-icons/react` — `CaretDownIcon` (the arrow icon)
- No other component dependency (a self-contained component)

## Accessibility

**Pattern**: Native `select` element

**Role**: Native `select`; the caret icon is hidden (`aria-hidden`).

**Keyboard**:

The native `select` behavior (arrows, typing, `Space` / `Enter` depending on the platform).

**Accessible name**: Required: a tied `Label` or an `aria-label`.

**Pitfalls**:

- The system picker is the most accessible one on mobile: that is why `rule-20` picks `NativeSelect` below `md`, **unless** the options need rich rendering (icons, descriptions) that an `<option>` cannot show.

## Code example

```tsx
import { NativeSelect, NativeSelectOption } from "@/components/ui/native-select"
import { Label } from "@/components/ui/label"

export default function Example() {
  return (
    <>
      <Label htmlFor="city">City</Label>
      <NativeSelect id="city" size="default">
        <NativeSelectOption value="">Choose a city…</NativeSelectOption>
        <NativeSelectOption value="boston">Boston</NativeSelectOption>
        <NativeSelectOption value="chicago">Chicago</NativeSelectOption>
        <NativeSelectOption value="seattle">Seattle</NativeSelectOption>
      </NativeSelect>
    </>
  )
}
```
