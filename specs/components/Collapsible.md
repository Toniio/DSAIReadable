## Role

A disclosure: a trigger that shows or hides one section of content.

## Usage

- Show or hide extra details in a side panel or a form
- Build collapsible sections in a FAQ or documentation
- Tuck advanced options behind a "More options" trigger
- Lighten a dense page by hiding secondary content
- Let the user decide how much information is on screen

## Constraints

- **MUST NOT** — serve as multi-level navigation → use `Accordion`
- **MUST** — make the trigger recognizable as interactive (a button or a link)
- **MUST NOT** — hide content the page needs to be understood at a glance
- **MUST NOT** — manage `aria-expanded` yourself: Radix does it

## Accessibility

**Pattern**: [Disclosure](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/) (Radix Collapsible)

**Role**: `CollapsibleTrigger` is a `button` with `aria-expanded` and `aria-controls`.

**Keyboard**:

| Key               | Action                     |
| ----------------- | -------------------------- |
| `Enter` / `Space` | Opens / closes the content |

**Accessible name**: The trigger text; when it holds only an icon (a caret), an `aria-label` is required.

**Pitfalls**:

- Closed content is removed from the accessibility tree: never hide information the user needs to go on.

## Code example

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@/components/ui/collapsible"

export default function Example() {
  return (
    <Collapsible>
      <CollapsibleTrigger>Show details</CollapsibleTrigger>
      <CollapsibleContent>
        <p>Extra content revealed on click.</p>
      </CollapsibleContent>
    </Collapsible>
  )
}
```
