## Role

Tabbed navigation that switches between mutually exclusive content panels; horizontal or vertical, in a default or a line style.

## Usage

- Organize related content into panels reached through tabs
- Switch between views without changing page ("Preview / Code")
- Group forms or settings by category with vertical tabs
- Tabbed navigation with an underline on the active tab (the `line` variant)
- Show conditional content in a tight space

## Constraints

- **MUST NOT** — serve as navigation between separate pages → use `NavigationMenu`
- **MUST NOT** — exceed 7 tabs per group
- **MUST NOT** — be used when several sections must be visible together → use `Accordion` (`Tabs` shows only one)
- **Note** — a `disabled` trigger stops receiving pointer events and takes `opacity-disabled`
- **MUST NOT** — make a panel's content depend on another tab

## Dependencies

- `Tabs` (Root, List, Trigger, Content) from `radix-ui`
- `class-variance-authority` for the `TabsList` variants (`tabsListVariants`)

## Anatomy

| -------------------------- | --------------------------------------------- |
| `data-slot="tabs"`         | Root; carries `data-orientation`              |
| `data-slot="tabs-list"`    | Container of the tabs; carries `data-variant` |
| `data-slot="tabs-trigger"` | A single clickable tab                        |
| `data-slot="tabs-content"` | Content panel tied to a tab                   |

## Accessibility

**Pattern**: [Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/) (Radix Tabs)

**Role**: `tablist`, `tab` (`aria-selected`, `aria-controls`), `tabpanel`.

**Keyboard**:

| Key                        | Action                                                     |
| -------------------------- | ---------------------------------------------------------- |
| `Tab`                      | Enters the list on the active tab, then moves to the panel |
| `ArrowRight` / `ArrowLeft` | Next / previous tab, activated (horizontal orientation)    |
| `ArrowDown` / `ArrowUp`    | Same, in the vertical orientation                          |
| `Home` / `End`             | First / last tab                                           |

**Accessible name**: The text of each tab; name the `TabsList` (`aria-label`) when several tab lists share the page.

**Pitfalls**:

- Tabs activate as focus moves: when a panel is expensive to render, pass `activationMode="manual"`.
- Tabs do not navigate between pages: use links for that.

## Code example

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/ui/tabs"

export default function Example() {
  return (
    <Tabs defaultValue="preview">
      <TabsList variant="line">
        <TabsTrigger value="preview">Preview</TabsTrigger>
        <TabsTrigger value="code">Code</TabsTrigger>
        <TabsTrigger value="settings">Settings</TabsTrigger>
      </TabsList>
      <TabsContent value="preview">Preview content.</TabsContent>
      <TabsContent value="code">Code content.</TabsContent>
      <TabsContent value="settings">Settings content.</TabsContent>
    </Tabs>
  )
}
```
