## Role

A two-state (pressed / not pressed) toggle button in several variants and sizes; its variants are exported for reuse (by `ToggleGroup`, for example).

## Usage

- Turn a visual option on or off (bold, italic, alignment)
- An on / off filter button in a toolbar
- A two-state control with immediate visual feedback
- Composed inside a `ToggleGroup` for exclusive or multiple choices

## Constraints

- **MUST NOT** — trigger an action that cannot be undone → use `Button`
- **MUST NOT** — stand in for a `Switch` in a settings form
- **MUST NOT** — combine the `outline` variant with a border on the parent
- **MUST NOT** — receive a function (callback, event handler) from a server component: it is a client component (`"use client"`), and only serializable props reach it from a server component
- **MUST** — give an icon-only `Toggle` an `aria-label`

- `class-variance-authority` — the variants (`toggleVariants`)

## Accessibility

**Pattern**: Toggle [button](https://www.w3.org/WAI/ARIA/apg/patterns/button/)

**Role**: A `button` with `aria-pressed`.

**Keyboard**:

| Key               | Action            |
| ----------------- | ----------------- |
| `Enter` / `Space` | Toggles the state |

**Accessible name**: The button text; an icon-only toggle needs an `aria-label` that names the action ("Bold"), not the state.

**Pitfalls**:

- The label must not change with the state: `aria-pressed` carries the state.

## Code example

```tsx
import { Toggle } from "@/components/ui/toggle"
import { TextBolderIcon } from "@phosphor-icons/react"

export default function Example() {
  return (
    <Toggle variant="outline" size="default" aria-label="Bold">
      <TextBolderIcon data-icon="inline-start" />
      Bold
    </Toggle>
  )
}
```
