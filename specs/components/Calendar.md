## Role

An interactive date picker built on `react-day-picker`: single, multiple or range selection, with month-by-month navigation.

## Usage

- Pick a single date in a form (a date of birth, a due date)
- Pick a date range (a billing period, time off)
- Show a calendar in a `Popover` for date-picker fields
- Navigate by month and year through the built-in dropdowns
- Show week numbers where the business context calls for them (`showWeekNumber`)

## Constraints

- **MUST NOT** — serve as a scheduler or planner (day or week views): the design system does not provide one
- **MUST NOT** — show more than one `Calendar` per view, **unless** comparing two date ranges
- **MUST** — place the `Calendar` inside a container (`Popover`, `Card`…): it does not position itself
- **MUST** — keep disabled days visible (`opacity-disabled`, `aria-disabled`)
- **MUST NOT** — break keyboard navigation (arrows between days, Tab to the controls)
- **Note** — the first and last days of a range take a raw `z-0` with `isolate`, so their highlight pseudo-elements paint under the day cells; internal to the component, declared in `tokens/allow-raw.registry.json` (`local-stacking`) and listed in `specs/foundations/elevation.md`

## Dependencies

- `react-day-picker` — the calendar engine and its types (`DayPicker`, `DayButton`, `Locale`)
- `Button` (`@/components/ui/button`) — navigation buttons and day cells
- `buttonVariants` (`@/components/ui/button`) — the navigation buttons' classes
- `CaretLeftIcon`, `CaretRightIcon`, `CaretDownIcon` (`@phosphor-icons/react`) — navigation icons
- `cn` (`@/lib/utils`) — the class-merging utility

## Accessibility

**Pattern**: A date [grid](https://www.w3.org/WAI/ARIA/apg/patterns/grid/) (react-day-picker)

**Role**: A grid of dates; the selected day carries `aria-selected`; an unavailable day is a `disabled` button.

**Keyboard**:

| Key                               | Action                            |
| --------------------------------- | --------------------------------- |
| `ArrowLeft` / `ArrowRight`        | Previous / next day               |
| `ArrowUp` / `ArrowDown`           | Same day the previous / next week |
| `Home` / `End`                    | Start / end of the week           |
| `PageUp` / `PageDown`             | Previous / next month             |
| `Shift+PageUp` / `Shift+PageDown` | Previous / next year              |
| `Enter` / `Space`                 | Selects the focused day           |

**Accessible name**: react-day-picker names the month navigation buttons, in English by default: pass localized labels through its `labels` prop.

**Pitfalls**:

- A calendar alone is not enough to enter a date the user already knows: offer a text input as well.
- Mark unavailable days by something other than color.

## Code example

```tsx
import { Calendar } from "@/components/ui/calendar"
import { useState } from "react"

export default function Example() {
  const [date, setDate] = useState<Date | undefined>(new Date())

  return (
    <Calendar
      mode="single"
      selected={date}
      onSelect={setDate}
      showOutsideDays
    />
  )
}
```
