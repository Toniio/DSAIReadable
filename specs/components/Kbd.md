## Role

An inline label that shows a keyboard key or a key combination.

## Usage

- Show a keyboard shortcut next to an action (`⌘K` for search, say)
- Show a key hint inside a `Tooltip`
- Document shortcuts on a help page or in a menu
- Group several keys with `KbdGroup` for combinations (`⌘` + `Shift` + `P`)

## Constraints

- **MUST NOT** — stand for anything but a keyboard key
- **MUST NOT** — add a click handler: the component is not interactive (`pointer-events-none`)
- **MUST** — check the contrast in the dark theme, on the actual background
- **MUST** — pair a symbol key (⌘, ⇧) with a text label for screen readers

## Accessibility

**Pattern**: Native `kbd` element

**Role**: Native `kbd`: marks a key or keyboard input.

**Keyboard**:

No interaction; purely informational.

**Accessible name**: The text. Screen readers read a symbol (`⌘`, `⇧`) inconsistently: spell the key out ("Cmd") or add `sr-only` text.

**Pitfalls**:

- The documented shortcut must actually exist, and must not clash with the browser's or the screen reader's own shortcuts.

## Code example

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"

export default function Example() {
  return (
    <div className="flex items-center gap-2">
      <span>Search</span>
      <KbdGroup>
        <Kbd>⌘</Kbd>
        <Kbd>K</Kbd>
      </KbdGroup>
    </div>
  )
}
```
