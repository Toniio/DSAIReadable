## Role

Secondary navigation that shows the path to the current page, so the user can climb back up the hierarchy.

## Usage

- Show the trail on pages two or more levels deep
- Let the user jump back to a parent page
- Show where the user stands in the site's hierarchy
- Collapse long paths behind an ellipsis in deep hierarchies

## Constraints

- **MUST NOT** — serve as primary navigation: it is a contextual landmark
- **MUST** — place a single `Breadcrumb` per page, at the top of the main content
- **MUST NOT** — make the last item (`BreadcrumbPage`) clickable
- **Note** — separators and the ellipsis are hidden from screen readers (`aria-hidden`)
- **MUST NOT** — replace the root's `aria-label="breadcrumb"`, **unless** to translate it
- **MUST** — in an interface that is not in English, translate the `UI_STRINGS.breadcrumb` strings (`srLabel` on `BreadcrumbEllipsis`)

## Dependencies

- `Slot.Root` from `radix-ui` (used when `asChild={true}` on `BreadcrumbLink`)
- `CaretRightIcon`, `DotsThreeIcon` from `@phosphor-icons/react`

## Anatomy

| Slot                               | Role                                                      |
| ---------------------------------- | --------------------------------------------------------- |
| `data-slot="breadcrumb"`           | Root `<nav>` with `aria-label="breadcrumb"`               |
| `data-slot="breadcrumb-list"`      | Ordered list `<ol>` that holds the items                  |
| `data-slot="breadcrumb-item"`      | One `<li>` of the trail                                   |
| `data-slot="breadcrumb-link"`      | Clickable link to a parent page                           |
| `data-slot="breadcrumb-page"`      | Current page, not clickable (`aria-current="page"`)       |
| `data-slot="breadcrumb-separator"` | Visual separator between items (a right caret by default) |
| `data-slot="breadcrumb-ellipsis"`  | Marks where a long path has been collapsed                |

## Accessibility

**Pattern**: [Breadcrumb](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/)

**Role**: A `nav` labelled `UI_STRINGS.breadcrumb.landmark` that holds an `ol`; `BreadcrumbPage` carries `aria-current="page"`.

**Keyboard**:

No interaction of its own: links behave natively (`Tab`, `Enter`).

**Accessible name**: The `nav` landmark is named "breadcrumb" by default; translate it through the prop provided. The ellipsis announces `UI_STRINGS.breadcrumb.ellipsis`.

**Pitfalls**:

- Separators are hidden (`role="presentation"`, `aria-hidden`): never put meaningful text in them.
- The current page is not a link: do not make it clickable.

## Code example

```tsx
import {
  Breadcrumb,
  BreadcrumbList,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbSeparator,
  BreadcrumbPage,
} from "@/components/ui/breadcrumb"

export default function Example() {
  return (
    <Breadcrumb>
      <BreadcrumbList>
        <BreadcrumbItem>
          <BreadcrumbLink href="/">Home</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbLink href="/products">Products</BreadcrumbLink>
        </BreadcrumbItem>
        <BreadcrumbSeparator />
        <BreadcrumbItem>
          <BreadcrumbPage>Product details</BreadcrumbPage>
        </BreadcrumbItem>
      </BreadcrumbList>
    </Breadcrumb>
  )
}
```
