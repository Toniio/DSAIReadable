## Role

A segmented input for one-time passcodes (OTP), with automatic movement between slots and an animated caret.

## Usage

- Verification codes (SMS, email, 2FA)
- Numeric PIN codes
- Confirmation codes of N digits or characters
- Two-factor authentication forms

## Constraints

- **MUST NOT** — take free text or more than 8 characters: it is meant for codes of 4 to 8 characters
- **MUST** — give each `InputOTPSlot` the `index` of its position
- **Note** — `spellCheck` is off by default: the browser offers no correction on a code
- **MUST NOT** — redefine the ARIA roles: the `input-otp` library handles them
- **MUST NOT** — receive a function (callback, event handler) from a server component: it is a client component (`"use client"`), and only serializable props reach it from a server component

## Dependencies

- `input-otp` — `OTPInput`, `OTPInputContext` (the OTP library)
- `@phosphor-icons/react` — `MinusIcon` (the default separator)

## Accessibility

**Pattern**: A single text input (input-otp) displayed as slots

**Role**: One real `input` takes the typing; the slots are visual; `InputOTPSeparator` carries `role="separator"`.

**Keyboard**:

| Key                        | Action                         |
| -------------------------- | ------------------------------ |
| Digits / letters           | Fill in the code slot by slot  |
| `Backspace`                | Deletes the previous character |
| `ArrowLeft` / `ArrowRight` | Moves the cursor               |
| Paste                      | Fills every slot               |

**Accessible name**: Required: a `Label` or an `aria-label` ("Verification code") on the input.

**Pitfalls**:

- Set `autoComplete="one-time-code"` so the code can be filled in automatically.
- Announce the error (an invalid code) with a linked message, not only through the slots' color.

```tsx
  InputOTP,
  InputOTPGroup,
  InputOTPSlot,
  InputOTPSeparator,
} from "@/components/ui/input-otp"

export default function Example() {
  return (
    <InputOTP maxLength={6}>
      <InputOTPGroup>
        <InputOTPSlot index={0} />
        <InputOTPSlot index={1} />
        <InputOTPSlot index={2} />
      </InputOTPGroup>
      <InputOTPSeparator />
      <InputOTPGroup>
        <InputOTPSlot index={3} />
        <InputOTPSlot index={4} />
        <InputOTPSlot index={5} />
      </InputOTPGroup>
    </InputOTP>
  )
}
```
