## Role

The provider for short-lived toast notifications, built on the `sonner` library, with custom icons and a theme that follows the app's.

## Usage

- Confirm that a user action succeeded (save, send, delete)
- Report a non-blocking error after an operation
- Show a temporary contextual warning
- Show that an asynchronous operation is loading
- Give a one-off piece of information without interrupting the flow

## Constraints

- **MUST NOT** — carry a critical message that requires an action → use `AlertDialog`
- **MUST** — place a single `<Toaster />`, at the root of the layout
- **MUST NOT** — show more than 3 toasts at once
- **MUST NOT** — exceed two sentences
- **Note** — `sonner` announces toasts to screen readers (`aria-live`)
- **Note** — a toast is square, like every surface of the system: `Toaster` sets `--border-radius` to `var(--radius-none)`, the one lever `sonner`'s own stylesheet leaves

## Dependencies

- `sonner` (external library) — the `Toaster` component and the `ToasterProps` types
- `next-themes` — the `useTheme` hook, to detect the theme
- `@phosphor-icons/react` — `CheckCircleIcon`, `InfoIcon`, `WarningIcon`, `XCircleIcon`, `SpinnerIcon`

## Anatomy

| Slot                  | Role                                                                                                                                                                                                                                                |
| --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-slot="toaster"` | Written on Sonner's `Toaster`, which does not forward it: no element of the DOM carries it. Target `ol[data-sonner-toaster]`, the list Sonner renders while a toast shows, with the `toaster group` class; each toast is an `li[data-sonner-toast]` |

## Accessibility

**Pattern**: Notifications (sonner)

**Role**: A `section` region named "Notifications"; a list of toasts in `aria-live="polite"`.

**Keyboard**:

| Key     | Action                                |
| ------- | ------------------------------------- |
| `Alt+T` | Moves focus to the notifications area |
| `Tab`   | Moves through the toasts' actions     |

**Accessible name**: The toast text is announced politely, without interrupting.

**Pitfalls**:

- A toast disappears on its own: never make it the only way to perform an action (undo must exist elsewhere), and leave it on screen long enough.
- For a blocking error, use an `Alert` or a form message, not a toast.

## Code example

```tsx
import { Button } from "@/components/ui/button"
import { Toaster } from "@/components/ui/sonner"
import { toast } from "sonner"

export default function Example() {
  return (
    <>
      <Button onClick={() => toast.success("All set! Your changes are saved.")}>
        Save changes
      </Button>
      {/* Mount the Toaster once, in the root layout, next to {children} */}
      <Toaster />
    </>
  )
}
```
